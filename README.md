# Banking Application

## Prerequisites

- Node.js 20.19+, 22.12+, or 24+
- npm 10+
- Angular CLI

## Setup

### Install the Angular CLI globally

```bash
npm install -g @angular/cli
```

### Clone the repo

```bash
git clone https://github.com/maxx-niu/banking-application.git
cd banking-application
```

## Install Deps

```bash
npm install
```

## Running

```bash
npm start
```

Open <http://localhost:4200/>.

## Building

```bash
npm run build
```

Output is written to `dist/banking-application/`.
